# Art direction and asset briefs

Use this page to brief any image, illustration or audio tool. Everything must be original; keep a license note for every file in the ASSETS ledger.

## Style in one paragraph

Flat vector toy-workshop look. Shapes are simple and chunky with a 2px dark navy outline (`ink`), flat fills from the palette, one hard offset shadow, no gradients, no glossy highlights, no texture except an optional blueprint grid. Characters and machines look like they are made from real parts: visible bolts, gears, axles. Friendly, curious, slightly quirky. Never scary.

## Generation prompt scaffold

"Flat vector illustration of [SUBJECT], chunky toy proportions, uniform 2px navy (#10243E) outline, flat fills using only #F5B700, #096A70, #2B62C9, #A83208, #10243E and #EAF1EF, one hard offset shadow, no gradients, no glossy highlights, no text, plain transparent background, centered, game asset."

Negative prompt: gradients, photorealism, 3D render, glossy, text, watermark, logo, existing game characters, franchise styles.

## Audio brief

- Music: upbeat, tinkering, marimba, pizzicato and light percussion. Three loops (workshop, garage, race) of 60 to 90 seconds, seamless.
- Effects: chunky snaps and clicks for parts, ratchet whirs for gears, soft "boop" for wrong attempts, a rising spring for success, a friendly "hmm" (not a buzzer) for a loss.
- Voice (optional): a warm read-aloud voice for every instruction and explanation.
- Rule: loss and error sounds are never harsh or lower than success sounds are loud.
